
# Weekly Microsoft 365 License Report

## Overview

This report provides a scheduled summary of Microsoft 365 license availability across the organization.

It was developed using Power Automate, Microsoft Graph API, and PowerShell to eliminate manual license tracking.

---

## Business Requirement

The IT team required a recurring report showing:

- Total licenses
- Assigned licenses
- Available licenses

The report is automatically generated and delivered by email every week.

---

## Technologies

- Microsoft 365
- Microsoft Graph API
- Power Automate
- PowerShell

---

## Business Benefits

- Eliminates manual license reporting
- Provides accurate license availability
- Supports license planning
- Helps IT Operations and Compliance teams
