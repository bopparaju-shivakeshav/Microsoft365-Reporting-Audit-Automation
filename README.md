# Microsoft 365 Reporting & Audit Automation

## Overview

This project demonstrates Microsoft 365 administrative reporting automation developed using Power Automate, Microsoft Graph API, and PowerShell.

The solution was built to automate recurring Microsoft 365 reports, reduce manual administrative effort, and support IT Operations, Compliance (ISMS), and Audit teams with accurate and scheduled reporting.

---

## Business Problem

Generating Microsoft 365 administrative reports manually required significant time and increased the risk of inconsistent reporting.

The objective was to automate recurring reports and deliver accurate information to stakeholders on a scheduled basis.

---

## Solution

The reporting solution automatically collects Microsoft 365 information, processes the data, generates reports, and distributes them through email.

---

## Reports Included

- Weekly Microsoft 365 License Report
- New Account Creation Report
- Deleted Account Report

---

## Technologies Used

- Microsoft 365
- Microsoft Graph API
- Power Automate
- PowerShell

---

## Business Benefits

- Reduced manual reporting effort
- Improved reporting consistency
- Better visibility into Microsoft 365 environment
- Supports IT Operations
- Supports ISMS compliance
- Supports Audit readiness
